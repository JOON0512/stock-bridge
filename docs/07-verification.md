# 구현 검증 기록

검증일: 2026-09-20, macOS, Python 3.14.0.

## 실행한 검증

1. `python3 -m unittest discover -s tests -v` — **50개 테스트 통과**.
2. `python3 -m trader demo` — 매수 접수, 중복 방지, 부분 체결, 잔량 취소, 매도 체결, 현금·보유수량 대조 성공.
3. `python3 scripts/check_contracts.py` — **3개 공식 명세 대조 통과**. 토스의 OpenAPI 요청 필드·enum, 키움 공식 JSON의 매수/매도 필드·경로, 한국투자 공식 함수의 본문 키·현행 TR 코드 확인.

테스트는 실제 키 없이 만든 응답과 로컬 모의 원장으로 수행했습니다. **증권사 인증 서버가 주문을 받아 실제 거래소에서 체결했다는 검증은 아닙니다.**

## 확인한 실패 상황

- 접수 직후 응답이 유실되는 경우: UNKNOWN 저장, 같은 ID 재전송 차단
- UNKNOWN 또는 전송 중 프로세스 종료 기록이 있는 경우: 계좌 신규 주문 중단
- 취소 응답 유실: 취소 재전송 차단, 원주문이 대기 중이라고 취소 실패로 추정하지 않음
- 프로세스 재시작과 동시 실행: 같은 계좌·ID에 주문 하나만 생성
- 예산·현금·수수료 여유·허용 종목·매도 가능 수량·가격 괴리·시각 초과
- NaN/Infinity/음수/소수 주식 수량/시각 시간대 누락 거부
- 원화·달러 예산 분리, 계좌번호 구분자 정규화
- 공식 API의 페이지 이어받기, 키움 계좌 불일치, 부호 붙은 시세 처리
- 토큰 캐시 재사용·만료 갱신·파일 권한, 조회 재시도와 주문 비재시도
- 키움에서 주문이 목록에서 사라져도 임의로 체결 완료 처리하지 않음

## 아직 필요한 실환경 검증

| 검증 | 상태 | 필요한 것 |
|---|---|---|
| 공식 문서 접근 | 완료 | 공개 문서 다운로드 및 버전 기록 |
| 로컬 주문 프로그램 실행 | 완료 | 현재 Mac에서 실행 |
| 토스 계좌 인증·시세·잔고 조회 | 미실행 | API 키·허용 IP·accountSeq |
| KIS 모의투자 인증·매수·매도·취소 | 미실행 | 모의 계좌와 별도 키 |
| 키움 모의투자 인증·매수·매도·취소 | 미실행 | 모의 키·허용 IP·계좌 |
| 실제 돈으로 첫 주문·체결·취소 | 미실행 | 사용자가 정한 주문·예산·실전 활성화 |
| 밤새 서버 운영·재부팅 복구 | 미실행 | 실행 위치와 서비스 운영 결정 |
| Windows·Linux 실환경 | 미검증 | 해당 환경 실행 검증 |

추가 권한이 필요한 곳에서는 요청대로 다음 구현으로 넘어갔습니다. 현재 남은 것은 위의 외부 인증/사용자 입력과 그 이후의 실환경 검증입니다. 권한을 받았다고 바로 실환경 검증까지 자동으로 통과하는 것은 아닙니다. 실제 응답을 보고 매핑·상품권한 차이를 수정할 수 있습니다.

## 현재의 명확한 한계

- 토스는 국내·미국 정수 수량 지정가, KIS/키움은 국내 KRX 현금 지정가만 구현했습니다.
- 로컬 모의 체결은 고정 가격으로 수동 진행됩니다. 수익률 백테스트가 아닙니다.
- KIS·키움은 시세 응답의 체결 원천시각 신선도를 토스와 같은 방식으로 검증하지 못합니다. 조회 성공이 최신 거래 체결을 의미하지 않을 수 있습니다.
- KIS·키움의 공휴일 캘린더, 시간외·소수점·시장가·주문 정정, 웹소켓, 자동 환전은 미구현입니다.
- 키움의 취소 완료·부분 체결 후 종료는 당일 조회만으로 확정하지 못하면 수동 대조가 필요합니다.
- 총 운용자산/평가손실 한도·손절 모델은 없으며 현재 한도는 주문 단위와 일일 주문 합계입니다.
- 같은 runtime의 로컬 잠금만 지원하고 여러 서버를 동시에 운용하는 분산 중복 방지는 없습니다.
- 수수료는 구매력 확인에 1% 여유를 기본 적용하지만, 실제 세금·수수료·체결가의 회계 원장은 증권사 내역을 기준으로 대조해야 합니다.

공식 소스 버전과 다운로드 해시는 `source-manifest.json`에 기록했습니다. 공개 원문은 `docs/reference/`에 보관하되 Git에서는 제외했습니다. 재현 시 공식 명세가 업데이트되면 다시 대조해야 합니다.
