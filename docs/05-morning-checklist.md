# 아침에 한 번에 처리할 일

프로그램과 조사·가이드는 준비되어 있습니다. **현재 실제 주문은 0건이고 실전 프로필은 모두 꺼져 있습니다.** 아래 외부 신청과 자금·주문 선택은 아직 입력받지 못했으므로 임의로 처리하지 않았습니다.

## 우선 한 증권사만 선택

| 목적 | 선택 |
|---|---|
| 기존 토스 국내·미국 보유주식을 그대로 연결 | **토스 Open API** |
| 증권사 모의투자를 먼저 거쳐 검증 | **한국투자 Open API** |
| 국내주식용 별도 대안 | **키움 REST API** |

세 증권사 모두에 계좌를 만들 필요는 없습니다. 가장 적은 준비로 시작하려면 토스 웹의 Open API 메뉴 제공 여부부터 확인하세요.

## 필요한 입력·신청

- [ ] 선택한 증권사 Open API 이용 신청과 약관 확인
- [ ] API 키·시크릿 발급 후 로컬 `.env`에 입력
- [ ] 토스·키움은 실행 컴퓨터/서버의 공인 IP 등록
- [ ] 계좌 조회 후 계좌번호/식별자가 맞는지 확인
- [ ] 자동매매에 별도로 배정할 실제 현금, 1회·하루 상한 결정
- [ ] 처음 확인할 종목·매수/매도·수량·지정가 결정
- [ ] 예측 모델 없이 실행할 테스트 주문의 시각과 만료시간 입력
- [ ] `preview`, `preflight` 확인 후 본인이 실전 활성화
- [ ] 첫 실제 주문·체결·미체결 취소를 증권사 앱과 대조

**키를 채팅으로 보낼 필요가 없습니다.** `.env`는 Git에서 제외되어 있습니다. 계좌 개설·현금 이체·API 권한 확대는 이번에 실행하지 않았습니다. 서버 계약·비용·항시 실행 서비스 설치도 아직 없습니다.

## 예산 설정

기본 투자 예산은 미설정입니다. 주문 직전 API의 현금 구매력과 매도가능수량을 확인합니다. 예시 설정에는 개인 계좌 내역이나 실제 자산 정보가 포함되어 있지 않습니다.

## 지금 가능한 확인

```bash
cd stock-bridge
python3 -m trader demo
python3 -m trader --profile toss_live doctor
```

첫 명령은 오프라인 모의 거래입니다. 둘째는 누락된 설정 이름만 보여주며 API 키가 없어도 실행할 수 있습니다.

이 체크리스트는 승인 대기 화면을 만들어 놓았다는 뜻은 아닙니다. 필요한 절차를 한곳에 모아 둔 것입니다. 각 증권사에서 실제 신청·본인 확인을 해야 키가 발급됩니다.
