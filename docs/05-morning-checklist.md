# Connection checklist

사용할 증권사의 설정 문서를 따라 연결합니다. 기본 설정에서는 실전 전송이 꺼져 있습니다.

## 필요한 입력·신청

- [ ] 선택한 증권사 Open API 이용 신청과 약관 확인
- [ ] API 키·시크릿 발급 후 로컬 `.env`에 입력
- [ ] 토스·키움은 실행 컴퓨터/서버의 공인 IP 등록
- [ ] 계좌 조회 후 계좌번호/식별자가 맞는지 확인
- [ ] 자동매매에 별도로 배정할 실제 현금, 1회·하루 상한 결정
- [ ] 처음 확인할 종목·매수/매도·수량·지정가 결정
- [ ] 예측 모델 없이 실행할 테스트 주문의 시각과 만료시간 입력
- [ ] `preview`, `preflight` 확인 후 실전 활성화
- [ ] 첫 실제 주문·체결·미체결 취소를 증권사 앱과 대조

.env에 저장한 키와 계좌 설정은 Git에 올리지 않습니다.

## 예산 설정

프로필별로 예산과 주문 한도를 설정합니다. 주문 직전에는 API의 현금 구매력과 매도가능수량을 다시 확인합니다.

## 지금 가능한 확인

```bash
cd stock-bridge
python3 -m trader demo
python3 -m trader --profile toss_live doctor
```

첫 명령은 오프라인 모의 거래입니다. 둘째는 누락된 설정 이름만 보여주며 API 키가 없어도 실행할 수 있습니다.
