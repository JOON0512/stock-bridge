# 주식 매매 자동화 — Stock Bridge

**실제 증권사 주문 API를 호출하는 프로그램을 구현했습니다. API 키와 계좌 설정이 없으므로 인증된 모의투자·실계좌 주문/체결 검증은 아직 하지 않았습니다.** 현재 기본 실행은 네트워크를 사용하지 않는 로컬 모의 거래입니다.

2026-09-20 기준 조사. 기존 토스 계좌 활용은 **토스 Open API**, 증권사 모의투자를 거쳐 시작하려면 **한국투자 Open API**, 국내주식 대안은 **키움 REST API**를 선택했습니다. 세 곳 중 하나만 연결하면 됩니다.

## 지금 바로 실행

이 Mac의 Python 3.14에서 실행했습니다. Mac/Linux Python 3.11 이상이면 기본 기능은 추가 라이브러리 설치 없이 동작합니다. Windows는 시간대 데이터와 파일 잠금 실환경 검증이 추가로 필요합니다.

```bash
cd stock-bridge
python3 -m trader doctor
python3 -m trader demo
python3 -m unittest discover -s tests -v
```

`demo`는 가상 현금 100만 원으로 시작해 고정 가격으로 **2주 매수 접수 → 중복 차단 → 1주 부분 체결 → 나머지 취소 → 1주 매도 체결**을 실행합니다. 결과는 `runtime/`에 남습니다. 종목코드와 가격은 연결 테스트 예시이며 매수 추천이나 현재 시세가 아닙니다. 실제 시장의 체결·수수료·세금·손익을 모사하지 않습니다.

## 구현 범위

| 기능 | 토스 | 한국투자 | 키움 |
|---|---|---|---|
| 인증·토큰 저장/만료 갱신 | 구현 | 구현 | 구현 |
| 계좌 확인·잔고·시세 조회 | 구현 | 구현 | 구현 |
| 매수·매도 | 국내·미국, 정수 수량 지정가 | 국내 현금, KRX 지정가 | 국내 현금, KRX 지정가 |
| 미체결 조회·잔량 취소 | 구현 | 구현 | 구현 |
| 체결 상태 대조 | 주문별 상세 | 주문일 조회 | 당일 조회, 확정 불가 시 수동 대조 |
| 증권사 모의투자 연결 | 공개 명세에서 별도 환경 미확인 | 구현, 별도 모의 키 필요 | 구현, 별도 모의 키 필요 |
| 인증된 실제 API 검증 | 키 미발급으로 대기 | 키 미발급으로 대기 | 키 미발급으로 대기 |

한국투자와 키움의 서비스 자체는 해외주식 API도 제공합니다. **이번 코드에서 해당 두 어댑터는 국내주식만 구현**했습니다. 현재 보유한 미국 주식의 거래 연결은 토스 어댑터가 담당할 수 있습니다.

공통 기능:

- 주문 JSON을 증권사별 요청으로 변환하는 미리보기와 실제 전송 명령
- 주문 직전 현금 주문가능금액·수수료 여유·매도가능수량 확인
- 종목 허용 목록, 1회/하루 금액, 하루 건수, 미체결 건수 한도
- SQLite 주문 원장, 영구적인 로컬 중복 ID 검사, 같은 계좌의 실행 직렬화
- 매수/취소 응답 유실을 결과 불명으로 기록하고 자동 재전송 차단
- 설정된 시각·가격 조건에 따라 주문하는 큐 실행기와 상태 동기화
- 신규 주문 비상 정지와 기존 주문 개별 취소

현재 매매 예측·종목 선정 모델, 시장가·소수점·신용·공매도·선물옵션, 자동 환전·입출금, 주문 정정 API, 웹소켓, 수익률 기반 손절 엔진은 구현 범위에 없습니다. 실전 매매 기능을 먼저 연결하고 전략 부분을 나중에 교체할 수 있는 구조입니다.

## 파일 구성

```text
trader/core.py        주문·예산 검사, 원장, 중복 방지, 상태 전이
trader/transport.py   HTTPS, 제한적 조회 재시도, 토큰 캐시
trader/brokers.py     토스 / KIS / 키움 / 오프라인 Paper 어댑터
trader/cli.py         실행 명령, 진단, 큐 실행, 복구
config.json          공유 가능한 기본 설정: 실전 비활성·실전 한도 0
.env.example         입력할 비밀 설정의 이름만 있는 양식
examples/            만료된 주문 양식; 그대로는 실전 전송 불가
tests/               실패 상황과 거래 수명주기 테스트
docs/                조사·실행 가이드·검증 기록
runtime/             로컬 주문 원장·토큰·모의 상태 (Git 제외)
private/             개인 자산 맥락·실사용 주문 파일 (Git 제외)
```

**원장과 토큰이 들어 있는 `runtime/`는 실전 운용 중 삭제하면 안 됩니다.** 이전 주문 ID와 일일 한도 사용 기록을 잃을 수 있습니다. 다른 컴퓨터로 옮길 때는 실행기를 멈추고 상태를 대조한 뒤 함께 옮겨야 합니다.

## API를 한 문장으로 설명하면

증권사에서 받은 키로 임시 출입증인 토큰을 발급받고, 프로그램이 **“이 계좌에서 이 종목을 이 가격에 몇 주 주문해 달라”**는 구조화된 요청을 HTTPS로 보내는 방식입니다. 응답의 주문번호로 이후 체결·취소 여부를 확인합니다. **주문 접수와 체결은 다른 상태입니다.**

이 프로그램은 그 연결 절차와 오류 처리를 담당합니다. 향후 예측 모델은 `Intent`와 같은 형식의 주문 후보만 만들면 됩니다. 모델이 증권사 어댑터를 직접 호출하지 않고 `Engine.submit()`을 거치도록 유지하세요.

## 공개 복사본 검증

2026-10-24에 오프라인 단위 테스트 50개를 통과했습니다. API 키·개인 계좌 내역·실제 주문 기록은 포함하지 않습니다. 증권사 인증 및 실제 주문 검증은 수행하지 않았습니다.

`scripts/check_contracts.py`는 별도로 내려받은 공식 명세(`docs/reference/toss-openapi.json`, `kiwoom-spec.json`, `kis-domestic.py`)가 있어야 실행할 수 있는 선택적 검사입니다. 이 외부 문서들은 공개 복사본에 포함하지 않았습니다. 해당 파일 없이도 단위 테스트와 로컬 모의 거래는 실행할 수 있습니다.
